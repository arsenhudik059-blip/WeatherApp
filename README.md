WeatherApp – moduł prognozy pogody (forecastWidget.js)
Aplikacja webowa do podglądu bieżącej temperatury, prognozy pogody, wilgotności oraz prędkości wiatru.

Funkcjonalności
Wyświetlanie aktualnych parametrów pogodowych (temperatura, wilgotność, prędkość wiatru).
Dynamiczna prognoza godzinowa i dzienna.
Czytelny interfejs w układzie dashboardu.

Technologie
HTML5
CSS3
JavaScript (Vanilla JS)

Mój wkład w projekt
Implementacja pliku forecastWidget.js – logika renderowania widżetu prognozy pogody (generowanie listy/kafelków z przewidywaną temperaturą na kolejne godziny i dni) oraz integracja z kontenerami w index.html.

Instrukcja uruchomienia
Sklonuj lub pobierz repozytorium.
Otwórz plik index.html w dowolnej przeglądarce internetowej.
